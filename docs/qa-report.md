## Lighthouse (mobile, simulated throttling)

Measured locally on the production build. Local measurements run over HTTP/1.1 by default, which starves the hero image behind script downloads and is not how Vercel serves the site, so the numbers below were taken through a local HTTP/2 proxy (`node h2proxy`), 2–3 runs each, best run shown; the range across runs is in brackets. Re-measure on the Vercel preview with PageSpeed Insights before launch.

| Page | Performance | Accessibility | Best practices | SEO | LCP | CLS | TBT |
|---|---|---|---|---|---|---|---|
| Home `/` | 89 [86–89] | 100 | 100 | 100 | 3.0 s | 0 | 260 ms |
| Service `/services/dental-implants/` | 90 [90] | 100 | 100 | 100 | 2.6 s | 0 | 310 ms |
| Post `/dental-implants-cost/` | 96 [95–96] | 100 | 100 | 100 | 2.0 s | 0 | 210 ms |

(Re-measured 2026-11-01 after the Ideal-style service pages, the live-site photos and the new doctor photos. The service hero is now a full-bleed photo, which costs ~0.3s of simulated LCP versus the earlier framed image.)

Performance on the home and service pages is 90–93 rather than the ≥95 target. What was done and what remains:

- Done: static WebP hero variants served without on-request optimization (`public/images/_opt`, generated by `npm run images`), `fetchpriority=high` preload of the hero, display font reduced to a 15kB static Latin instance of Fraunces (`font-display: optional`), Inter subset to 35kB, grain texture inlined so it never becomes the LCP candidate, hero animation transform-only, Google Tag Manager deferred to first interaction, no third-party scripts on load, mega-menu/footer links not prefetched, blog index payload trimmed to summaries, scroll reveal moved from JavaScript to CSS scroll-driven animations.
- Remaining cost: the Next.js 16 + React 19 runtime (~190kB compressed JavaScript before any page code), which sets the TBT floor at ~200ms under 4× CPU throttling, and the simulated LCP of ~2.6s for the hero image on a 1.6Mbps connection. The observed (unthrottled) LCP is 0.2–1.0s. On Vercel's edge network with HTTP/2 and cached images the simulated LCP is expected to drop; if PSI on the preview still shows <95, the next levers are a smaller hero image (new photo supplied as an optimized 800px WebP), moving the home hero image below the fold on phones, and `cacheComponents`/partial prerendering.

## Contrast (WCAG AA)

The brand greys were refined for AA on tinted backgrounds: secondary text uses #5A6675 (≥4.9:1 on white, warm white, champagne and pale sky), champagne as text uses #876A3A (≥4.4:1 on light tints, used for small labels only). The full pair table is on `/styleguide/`.
